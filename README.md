# Juan García Nila — academic website

A responsive static academic website designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload everything in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then `main` and `/ (root)`.
5. Your site will appear at `https://YOUR-USERNAME.github.io/`.

## Customize

- Replace the `JGN` placeholder in `index.html` with an image: `<img src="assets/profile.jpg" alt="Juan García Nila">`.
- Add `.portrait img { width:100%; height:100%; object-fit:cover; border-radius:50%; }` to `styles.css`.
- Replace or add links to Google Scholar, GitHub, ORCID, and LinkedIn in `.sidebar-links`.
- Edit news directly in the `#news` section of `index.html`.

No build tools or dependencies are required.
